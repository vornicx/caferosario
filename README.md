# El Café de Rosario — Archic V19

Proyecto web completo, estático y componentizado. Esta versión consolida la dirección visual de Rosario con el estándar Archic: identidad propia, fotografía representativa provisional + recurso real, carta HTML, mobile específico, motion funcional y cuatro rutas reales.

## Comandos
- `npm run dev` — build + servidor local
- `npm run check` — validación estructural, rutas, assets, responsive/reduced-motion
- `npm run build` — genera `dist/`

## Rutas
- `/`
- `/carta/`
- `/el-cafe/`
- `/visitanos/`

## Dirección V19
**Rosario cambia con la hora.** La web usa la variedad real del negocio —desayuno, tostada, merienda, algo dulce— como estructura, no como decoración.

Ver `DESIGN_DIRECTION.md` y `ARCHIC_QA.md`.
